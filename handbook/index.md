# JAX Diagnostics

JAX Diagnostics adds a repair guide to failures in JAX training and inference programs. A matched error gets a stable diagnostic ID, a guide link, and a verification procedure. The same diagnostic catalog powers the Python wrapper, command-line router, and agent skill.

- Start with the [quickstart](quickstart.md) for a small, reproducible JAX failure.
- Read the [Python API](python-api.md) to integrate diagnostics at a training entry point.
- Use the [CLI and agent skill](cli-and-skill.md) when you have a saved traceback.
- Browse [the diagnostic catalog](diagnostics.md) for exact exceptions and symptoms.
- Read the [launch article](blog/repair-links-in-tracebacks.md) for the rationale and a worked example, or the [roadmap](roadmap.md) for gaps.
