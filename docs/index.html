Debug JAX errors from the traceback.

Get a repair link for tracer errors, NaNs, and accelerator failures. Add one wrapper to your Python training entry point or install the agent skill to diagnose saved errors.

Add to train.py

Use it in your training script

Install with Python 3.11 or newer. Wrap the host-side entry point, outside JIT. When a failure matches a guide, the wrapper adds a note and re-raises the original exception.

Install with pip

After the first PyPI release:

python -m pip install jax-diagnostics

Until then, install from GitHub.

python -m pip install "git+https://github.com/mlnomadpy/jax-diagnostics.git"

train.py

from jax_diagnostics import annotate_errors

if __name__ == "__main__":
    with annotate_errors():
        main()

Install the agent skill

Run this in your project with Node.js 22.20 or newer. Choose your coding agent when prompted.

npx skills add mlnomadpy/jax-diagnostics

JAX debugging guides

The catalog covers all 12 public JAX exception types at the pinned revision. It also routes common backend and training symptoms.

  • TracerBoolConversionError

    Check for a traced value in Python control flow. Use JAX control flow for data-dependent branches.

  • NaNs and infinities under JIT

    Find the first non-finite operation while keeping the original inputs, precision, and backend.

  • GPU and TPU out-of-memory errors

    Identify the failing allocation and inspect per-device shapes, sharding, and temporary buffers.

  • KeyReuseError

    Trace where a random key was consumed and verify that independent operations receive separate keys.
