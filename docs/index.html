A repair guide in every matched traceback.

Link a JAX failure to the checks that help you diagnose it. Add one wrapper to your training entry point and run your script as usual.

Add to train.py

Use it in your training script

Install with Python 3.11 or newer. Wrap the host-side entry point, outside JIT. On failure, the wrapper adds a note and re-raises the original exception.

Install from GitHub

python -m pip install "git+https://github.com/mlnomadpy/jax-diagnostics.git"

train.py

from jax_diagnostics import annotate_errors

if __name__ == "__main__":
    with annotate_errors():
        main()

Install the agent skill

Run this in your project with Node.js 22.20 or newer. Choose your coding agent when prompted.

npx skills add mlnomadpy/jax-diagnostics
